# PDF font

`WaypointSans.ttf` is a static regular-weight subset of Noto Sans SC from the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/notosanssc). It includes the original font's Basic Multilingual Plane glyphs, including Latin and common Chinese characters, for portable PDF export without a network connection.

The redistributed derivative was renamed Waypoint Sans and is licensed under the SIL Open Font License 1.1. See `OFL-NotoSansSC.txt`. It is used only by the backend; it is not included in the Angular browser bundle.
