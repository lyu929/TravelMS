# TravelMS personal edition

This project has been extended into **Waypoint**. The current setup instructions, demo accounts, workflows, and test commands are in [README.md](README.md).

Use `npm run setup -- --demo` for a backed-up migration and local sample data, then `npm start` to run the frontend and API together. Existing records and passwords are preserved.

The original TravelMS course project remains the foundation. Keep its provenance and applicable license/attribution when sharing the personal edition.
